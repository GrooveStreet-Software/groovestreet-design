This study needs to be served over HTTP

The scene is an ES module, and browsers refuse to load a module from a file:// path. That is a security restriction, not a fault in this page, and no markup change can work around it. 

cd glass
node serve.mjs

serve.mjs ships in this folder and uses only Node built-ins, so there is nothing to install. Then open http://localhost:3000.
