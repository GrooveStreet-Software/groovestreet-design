# GROOVESTREET — Design. Build. Ship.

**GROOVESTREET** is a design studio site built with **Next.js 15**, **TypeScript** and **Tailwind CSS**, available in **English**, **French** and **German**.

---

## Getting Started

### Requirements

- **With Docker:** Docker only. Nothing else to install.
- **Without Docker:** Node.js 22 or later and npm (included with Node.js).
